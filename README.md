# Sree Svadista Prasada

Food ordering and Dabba Wala tiffin-subscription web app for a South Indian home kitchen in Milton Keynes.

- `ssp-nextjs/` — the live website (Next.js 16, Vercel)
- `backend/` — the API (FastAPI + MongoDB, Render), all routes under `/api`
- `docs/ops/` — programme records: brief, phase specs, decisions, risks, launch checklist, audits
- `frontend/`, `mobile/` — legacy; not deployed

How to run, test and deploy: see `CLAUDE.md`. Change history since 2026-08-28: `docs/ops/BUILD_LEDGER.md` (this `CHANGELOG.md` stopped there).
